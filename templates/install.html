MySQL 数据库

在宝塔「数据库 → 添加数据库」里建一个库和用户（记下库名、用户名、密码），填到这里。 库不存在时安装程序会自动创建；表结构全部自动建立。

只能包含字母、数字、下划线

站点信息

显示在页面标题和邮件里
可选；用于给用户展示完整的调用示例地址

邮箱发信（SMTP）

注册需要邮箱验证码，所以必须配置。QQ 邮箱请用「授权码」而不是登录密码。

465 = SSL，587 = STARTTLS

管理员账号

这个账号用来管理 API、用户、卡密和日志，请妥善保存。

注册即赠送的积分数量，安装后也能在「全局设置」里改
点击安装后会依次：建库 → 建表 → 写入 SMTP 等设置 → 创建管理员 → 生成 config.json 和 install.lock。 重复点击不会破坏已有数据（表结构使用 IF NOT EXISTS）。

装好后请删除或重命名 install.lock 之外没有别的要动的地方； 重装需先删除 install.lock。
